# Security Policy

## Supported Versions

Security updates are actively provided for the following versions of Feather Browser:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security and privacy are the highest priorities for Feather Browser.

If you discover a security vulnerability or privacy leak within this repository, please do **NOT** open a public issue.

Instead, please report it responsibly by:
1. Opening a **Draft Security Advisory** on GitHub via [Security Advisories](https://github.com/aanneion/lightweight_browser/security/advisories/new) (preferred).
2. Or contacting the repository maintainer directly through GitHub.

### What to include in your report
- A detailed description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
- Android version(s) and device model(s) tested.

### What to expect
- An acknowledgment of your report within 48 hours.
- A status update with validation results and expected timeline for a patch.
- Credit in release notes once the patch is published (unless you request anonymity).
